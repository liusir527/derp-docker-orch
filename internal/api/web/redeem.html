使用教程
  1. 复制上方 derpMap JSON。
  2. 打开 Tailscale 管理台 → ACL,把 derpMap JSON 粘贴进 policy 文件顶层,保存。
  3. 节点重启 tailscale:tailscale up 或重启服务。
  4. 验证:tailscale netcheck 应看到本中继 region;tailscale ping <对端> 输出 via DERP(...) 表示中继生效。
